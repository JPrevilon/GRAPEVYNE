# Visual evidence index

Prompt-specific evidence is additive. A later phase must not delete, overwrite,
or relabel an accepted earlier phase's evidence.

| Phase | Evidence index | Scope |
| --- | --- | --- |
| Prompt 10A1R | [`prompt-10a1/README.md`](prompt-10a1/README.md) | Accepted cinematic rebuild, product regressions, model comparisons, and local walkthrough |
| Prompt 10A2 | [`prompt-10a2/README.md`](prompt-10a2/README.md) | True-black transitions, forward/reverse anti-flash evidence, direct bottle/grape rotation, and fallback modes |

Each phase index states whether artifacts are local or hosted, identifies its
accepted base/release context, and records hashes only after captures exist.
Neither local nor Preview evidence is Production proof.
